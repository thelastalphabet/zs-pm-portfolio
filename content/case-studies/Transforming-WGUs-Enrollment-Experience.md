# Slide 9

FLAGSHIP PROJECT

RN License Validation: A Complete Redesign

The Challenge

2,500+ monthly license validations with 33% requiring manual review. The decade-old OnBase solution processed licenses but had severe limitations—only 25% of flagged items had actual issues, wasting precious staff time.

The breaking point: legacy workflows required Banner IDs unavailable in our new self-service system. We had to redesign or fail.

The Solution

Created direct SSE Orchestrator-to-Nursys integration, relegating OnBase to document archival only. Added self-service resubmission capabilities for applicants with data errors.

Reduced repetitive PII entry, implemented smart error notifications, and automated transfer evaluation object creation in Salesforce.
