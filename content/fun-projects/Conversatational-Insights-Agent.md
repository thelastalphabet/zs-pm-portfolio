## Conversational Insights - Perfecting conversational experiences
# Created an agent that enables non-UX experts to evaluate what good looks like when it comes to conversations with a chatbot

# Problem to Solve
A chatbot that ignores conversational design principles doesn't just frustrate users-it erodes trust and kills adoption. For non-UX experts, determining what a "good" model response looks like can be challenging. Does it truly follow conversational design principles?
Does it align with the UX guidelines it was trained on? The bigger challenge is defining what good actually means.

## Solution
The agent evaluates chatbot responses against established UX guidelines on conversational design principles, identifying which parts align with the guidelines and which do not. It provides actionable insights to improve conversation quality and user experience.
You can update the knowledge as the UX guidelines are modified and it will continue to give feedback according to the latest guidelines.
You can also copy the recommendations and prompt engineer into the model improving the model response instantaneously!
The agent can be used for any conversation and not just limited to a chatbot.

Impact
Without this agent I struggled to come up with what good looks like, and what sections of a response met the UX guidelines and what didn't.

I also struggled with defining conversation starters. With this tool, I can simply plug in a response and it clearly calls out the gaps and where the response does not align with the provided UX guidelines.
